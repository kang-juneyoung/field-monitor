# 0001. 폐쇄망에서 동작하는 지도

**상황** 현장 장비 관제는 인터넷이 없는 환경에서 돈다. 온라인 지도 API(구글·카카오 등)나 공개 타일 서버를 쓸 수 없다.

**결정**
- 지도 라이브러리(Leaflet)를 저장소에 포함한다. 화면이 외부 URL을 하나도 요청하지 않는다.
- 지도 타일은 MBTiles(SQLite 파일 하나)로 배포하고 서버가 `/tiles/{z}/{x}/{y}.png`로 꺼내 준다.
  MBTiles는 TMS 좌표계(y가 아래에서 위로)라 웹 지도(XYZ)의 y를 뒤집어 조회한다.
- 타일은 인터넷 타일 서버에서 내려받지 않고, 공개 벡터 데이터를 `tools/build_mbtiles.py`로 직접 그려 만든다.
  샘플은 통계청 행정구역 경계(2013)로 만든 송도 일대 지도(줌 11~16, 약 1,500장, 1.7MB)다.
- 타일 파일이 없을 때도 위치 관계를 볼 수 있도록 화면이 위경도 격자를 직접 그린다.

**결과** 지도 파일 하나만 바꾸면 다른 지역·다른 원천 데이터(OSM 추출본, 수치지도 등)로 교체할 수 있다.
실제 운용 지도는 도로·지형이 들어간 데이터로 같은 도구를 확장하거나, 기존 MBTiles를 그대로 쓰면 된다.

**검증** `tests/test_tiles.py` (y 뒤집기, 좌표 투영, 타일 개수, PNG 생성)
